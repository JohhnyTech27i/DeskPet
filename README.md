Cool Sans Desktop pet
--------------------
This repo holds the code for a software that allows you to have sans run in your desktop.

Features
---------
-Click to see current time based on your OS
-Double click to see sans say "You Clicked"
-A pop menu with three options; quit, sit, talk
- A timer that says I am sans every 3 seconds
- You can drag sans with the left click of your mouse
- Certain inputs that perform certain actions
  - Press H for sans to say "Click me"
  - Press P to stop the timer
  - Press R to resume the timer
 
  Note: When downloading the project on itch.io, your computer might not let you so press run anyway, because this program is not a virus, it is just that it doesn't identify the publisher.
  
  Characters are from undertale which belongs to toby fox!
